常见问题

七个问题的答案都在下面，展开着，不用点。

如何加入 NEX 服务器？

打开 Minecraft Java 版客户端，点「多人游戏」→「添加服务器」，把服务器地址复制进去，点完成即可。服务器几乎支持所有 Java 版本（不支持快照版和愚人节版本）。

我无法连接到服务器，怎么办？

先检查版本是否正确（不支持快照版和愚人节版本）；服务器维护期间无法加入，维护消息会在群里同步；再检查网络是否正常，必要时重启游戏或电脑。

登录提示「无法连接到身份验证服务器」怎么办？

离线账号请先到 NameMC 查询用户名是否与正版玩家重复，如有请联系服主。

服务器支持手机版吗？

手机也能玩。不过要注意我们只支持国际版 Minecraft，网易版暂时不行。

不小心破坏了他人的东西怎么办？

只是几块方块的话，悄悄补回去就好，还可以放个告示牌道个歉（可选）。

我被处罚了 / 被禁言了，怎么办？

如果你觉得有误会或不公平，直接申诉就好。把情况说清楚，最好提供截图或录像当证据，我们会认真调查，保证给你一个公正的处理结果。

有哪些规则需要遵守？

详见服务器规定栏目，共 17 条，涵盖建筑、行为、社区交流等各个方面。完整规则请看 官方 Wiki，看不懂的地方随时问管理员。
