NEX 官网

一个 Minecraft 群组服务器的官网：纯静态、零依赖、手写 CSS/JS，带真实在线的数据、跟随鼠标的图片墙和深浅色切换。

线上预览 · 更多截图 · 本地运行 · 许可

这个站在做什么

  • 首页只靠排版立住：第一屏是一句大字，下面紧接着一条「服务器列表条目」——名字、版本、MOTD、在线人数、三条线路状态，全部来自 Minecraft MOTD 接口的真实数据。
  • 数据是真的：在线人数来自公网 MOTD 查询；主机 CPU / 内存 / 实例数来自自建接口。读不到就显示 —，不会编数字。
  • 图片墙跟着鼠标走：initGrid() 生成 4×7 的斜置网格，鼠标移动时四行以不同权重反向滑动，松手自动收敛。只有 transform，不常驻动画。
  • 深浅两套色：一套语义化颜色令牌，html.theme-light 整体覆盖；选择存 localStorage，</head> 前注入脚本防闪白。
  • 动效克制：统一 cubic-bezier(.16,1,.3,1)，位移 16px，时长 0.85–1s；prefers-reduced-motion 下内容立即出现、不做位移。
  • 没有框架和图标库：不用 Tailwind、不用 UI 库、不用 Font Awesome，图标是内联 SVG，字体自托管（Barlow / Barlow Condensed），首屏不需要任何第三方请求。

技术栈

项目 选择 说明
页面 手写 HTML，片段拼装 build.mjs 把 partials/ 内联进 9 个模板
样式 手写 CSS，约 900 行 语义化颜色令牌、单一栅格、两档圆角
脚本 原生 JS，约 13 KB 无构建步骤、无打包器
构建 Node 单文件脚本 只做字符串拼接与版本号哈希
字体 自托管 woff2 Barlow Condensed + Barlow，中文回落系统黑体

  partials/             nav.html / footer.html / icons.html
  css/site.css          全部样式与设计令牌
  js/setting.js         站点配置：地址、线路、社交链接、首页语录
  js/site.js            交互：实时数据 / 图片墙 / 复制 / 赞助流程 / Wiki 同步

重新发布.bat            Windows 双击构建
css/ js/ *.html         构建产物，可直接被静态托管
docs/shots/             README 截图
picture/ webfonts/      图片与自托管字体

本地运行

node build.mjs            # 生成页面
npx serve .               # 或者 python -m http.server / 任意静态服务器

直接双击 index.html 也能看，只是 /api/* 请求会 404，页面会显示 —，不会报错。

换成你自己的服务器

  1. 配置：src/js/setting.js 里改服务器地址、线路列表、社交链接、首页随机语录。
  2. 文案：直接在 src/*.html 里改；导航和页脚在 src/partials/，改一次全站生效。
  3. 配色：src/css/site.css 顶部的 :root（深色）和 html.theme-light（浅色）两块。
  4. 图片：替换 picture/ 下的同名文件 —— cover-*.jpg 是封面，gridmotion/g01..g18.jpg 是图片墙素材，avatar-*.jpg 是团队头像。
  5. 赞助二维码：把 picture/pay-*.jpg 换成自己的收款码（仓库里是占位图）。

数据接口

页面会请求下面这些地址，都可以替换或直接删掉：

用途 地址 说明
在线人数 motd.minebbs.com/api/status 公网 Minecraft MOTD 查询，逐条查线路
主机数据 /api/host 需自建，返回 cpu memPercent running total uptime 等字段
更新日志 /api/wiki-changelog 失败回退到 GitHub raw 和镜像，三级
支付验证 /api/pay-turnstile-verify 示例中已停用，见 initDonate 注释

部署

  • GitHub Pages：仓库根目录本身就是构建产物，Settings → Pages 选 main 分支根目录即可。
  • 自己的服务器：把整个目录丢给 nginx root 指过去，静态文件即可；/api/* 用 proxy_pass 反代到你自己的服务。
